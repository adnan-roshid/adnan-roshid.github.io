# Adnan Roshid Shawon - Professional Academic Website

A clean static website built for GitHub Pages.

## Fresh deployment
1. Create a public GitHub repository named `adnan-roshid.github.io`.
2. Upload the contents of this folder to the repository root.
3. In repository **Settings > Pages**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. The site will publish at `https://adnan-roshid.github.io`.

See `EDITING-GUIDE.md` for updates.
